# Jamal Life

Личная система на каждый день: этапы дня, задачи с напоминаниями, цели, деньги, заметки и AI-разбор.
Работает офлайн и синхронизируется через Supabase между телефоном, компьютером и браузером.

| Где | Как установить |
| --- | --- |
| Android | `JamalLife.apk` из последнего [релиза](https://github.com/Doxajooon/life/releases/latest) |
| Windows | `JamalLife.exe` из последнего [релиза](https://github.com/Doxajooon/life/releases/latest). Закрытие окна сворачивает приложение в трей, напоминания продолжают приходить. В меню значка есть пункт «Запускать вместе с Windows» |
| Браузер | https://doxajooon.github.io/life/ (можно установить как приложение) |

## Как устроен проект

```
index.html            всё приложение (один файл: разметка, стили, логика)
sw.js                 офлайн-режим; запросы к Supabase никогда не кэшируются
manifest.webmanifest  установка как приложение
icon.svg, icon-*.png  иконка Jamal Life
android/              оболочка Android (WebView, точные будильники, канал уведомлений со звуком)
desktop/              оболочка Windows (WPF + WebView2, трей, уведомления Windows, автозапуск)
supabase/             SQL-схема и Edge Function для AI (Gemini)
tests/                static_qa.mjs (структура) и e2e.mjs (браузерные тесты с имитацией Supabase)
tools/sync-platforms.mjs  копирует веб-файлы в android/ и desktop/ перед сборкой
```

Источник один — файлы в корне. Копии в `android/app/src/main/assets` и `desktop/Web` создаются командой `npm run sync`
и в репозиторий не попадают.

## Синхронизация

- Вход по email и паролю (Supabase Auth). Токен обновляется сам; если сессия отозвана — приложение просит войти,
  а все записи остаются на устройстве и отправляются сразу после входа.
- Фоновая проверка раз в 15 секунд запрашивает только время последнего изменения; полная копия скачивается,
  лишь когда в облаке что-то поменялось, и экран перерисовывается только при реальных изменениях.
- Запись в облако условная (по версии строки), поэтому два устройства не затирают друг друга. Если правки
  были на обоих, они объединяются по записям: новые и удалённые доходы, расходы, заметки и задачи учитываются с обеих сторон.

## Напоминания

- Этапы дня и задачи со временем: напоминание заранее (за 5–60 минут, выбирается в задаче) и в момент задачи.
- Мелодия Jamal Life. На Android она звучит через отдельный канал уведомлений даже при закрытом приложении.
  На Windows приходит уведомление из трея, в браузере — системное уведомление.
- Если устройство спало, пропущенное напоминание всё равно придёт в течение 10 минут.
- Проверить звук: «Уведомления» → «Проверить звук».

## Разработка

```bash
npm install && npx playwright install chromium
npm test            # структурные проверки
npm run test:e2e    # браузерные тесты: экраны, формы, синхронизация двух устройств, истечение сессии, напоминания
```

Каждый push в `main` запускает GitHub Actions: тесты, затем сборку APK и EXE, затем релиз с файлами.
Для обновления APK поверх старой версии добавь секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`,
`ANDROID_KEY_ALIAS` — иначе каждая сборка подписывается новым ключом.

## Supabase

- Проект `riqmwueobjazfnhvvumy`, таблицы `public.life_state` (данные, одна строка на пользователя) и
  `public.ai_usage` (лимит AI: 10 запросов в час). Схема — `supabase/setup.sql`, везде включён RLS.
- Edge Function `life-control-ai`: модель Gemini, ключ только в Secrets как `GEMINI_API_KEY`.
- В Auth → URL Configuration должен быть адрес `https://doxajooon.github.io/life/` (для письма сброса пароля).
