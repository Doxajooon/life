3. **Карточка «Динамика дня» не показывалась.** Код писал в несуществующие элементы. Разметка добавлена.
4. **Пустая иконка у кнопки «Выйти».** Не было значка `i-x`. Добавлен, тест проверяет, что все используемые иконки определены.

6. **Android:** нет иконки приложения (добавлена, адаптивная), системная иконка уведомлений заменена своей, на Android 15 страница уходила под статус-бар (добавлены отступы под системные панели и клавиатуру), цвет панелей синхронизируется с темой приложения, кнопка «Назад» переведена на современный API, точные будильники на Android ниже 12 работали неточно.
7. **CI:** образ `ubuntu-24.04` вместо `ubuntu-latest` (меняется 19 октября), отмена устаревших сборок при частых пушах, необязательный постоянный ключ подписи APK, таймауты.
8. **Прочее:** `schema_version` по умолчанию 56 в SQL (как в живой базе), `VERSION.txt`, `BUILD_STATUS_RU.txt`.

## Анимации
Плавное появление блоков при смене вкладки, «прыжок» иконки в нижней навигации, покачивание иконок при наведении, пульс точки уведомлений, блик на полосах прогресса, появление модальных окон. При включённом системном «уменьшить движение» всё отключается.

## Как получить APK
1. Загрузить файлы из архива в репозиторий (папка `.github` скрытая: файл `release.yml` добавить через «Add file → Create new file» с путём `.github/workflows/release.yml`).
2. GitHub → Actions → Life Control Release → дождаться зелёного статуса.
3. Внизу страницы запуска, раздел Artifacts → `life-control-v56-debug-apk`.

Чтобы новый APK обновлял старый без удаления: добавить в Settings → Secrets → Actions значения `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
