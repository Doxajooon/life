# Life Control V57 — редизайн

## Экраны
1. **Вход** — горы и корона, «Life Control V57», email по умолчанию, глазок у пароля, «Запомнить меня», «Забыли пароль?», «Создать аккаунт». Только Supabase email + пароль, входа через Google нет.
2. **Сегодня** — шапка (поиск, колокольчик со счётчиком, настройки), чипы разделов, нижняя навигация из 4 пунктов (Сегодня, Цель, Деньги, Заметки; профиль — через «Настройки → Профиль»), «Пульс жизни» из 5 колец, карточка главной цели, «Мои деньги» за месяц с мини-графиком, задачи на сегодня (свои задачи и этапы расписания). Прежние блоки (мотивация, «Сейчас», контрольная панель, итог дня) лежат в «Подробностях дня».
3. **Цели** — список целей с прогрессом и сроком. Подробности главной цели (капитал, этапы, AI-план) сохранены.
4. **Цель** — обложка, название, сумма, срок, описание, иконка, цвет, «Пополнить», «Сделать главной», удаление.
5. **Деньги** — Обзор / Транзакции / Календарь, график доход/расход с линией баланса (7 дней / 30 дней / 3 месяца / год), кнопки Доход / Расход / Перевод. Бюджеты, долги, аналитика и учёт по дням остались.
6. **Календарь** — месячная сетка с точками операций, итоги месяца, операции выбранного дня, добавление на выбранную дату.
7–8. **Заметки** — поиск, категории Личные / Работа / Идеи, полноэкранный редактор (жирный, курсив, список). Корзина осталась.
9–10. **Настройки и режим отображения** — профиль, смена пароля, синхронизация, тема, размер текста, переключатели уведомлений, Мобильный / ПК. Старые настройки (расписание, касса, AI, импорт) — в «Расширенных настройках».
11. **Уведомления** — фильтр Все / Задачи / Финансы / Цели, отметка прочитанного.
12. **Профиль** — инициалы, статистика из данных, экспорт JSON, резервная копия на устройстве, выход.

## Сверка с макетом (`docs/mockup.png`)
- **Вход**: без карточки, на весь экран тёмное небо, закатное свечение и горы; корона, «Life Control» и «V57» под ним, девиз в три строки, поля с подсказками «Email» / «Пароль», «Забыли пароль?» и «Создать аккаунт» по центру. Входа через Google по-прежнему нет.
- **Шапка**: иконки во вкладках, все четыре вкладки помещаются на телефоне. На подэкранах (цель, заметка, настройки, режим, уведомления, профиль) на телефоне нет шапки приложения и нижнего меню, только строка «← Заголовок». В режиме ПК всё как раньше.
- **Сегодня**: дата справа в «Пульсе жизни»; под каждым кольцом статус (Хорошо / Нормально / В процессе / Слабо / Критично), цвет кольца по статусу. Компактная карточка главной цели на горном фоне: «Осталось N дней», сумма, полоса с процентом, «Собрано / Осталось». Суммы в «Моих деньгах» в одну строку, валюта под числом. Квадратные чекбоксы у задач.
- **Цели**: цветные иконки, процент рядом с полосой. Редактор: круглая обложка, подписи «Название цели», «Целевая сумма (валюта)», «Срок достижения», «Описание (необязательно)», иконки и цвета кружками.
- **Деньги**: четыре суммы в ряд, блок «Быстрое добавление» с цветными кнопками Доход / Расход / Перевод.
- **Заметки**: поиск, корзина и «+» в одной строке. Редактор: поля «Заголовок», «Категория», «Текст заметки», панель форматирования под текстом.
- **Режим отображения**: переключатель внизу карточки и список преимуществ. **Профиль**: статистика списком.

## Данные
- Миграция v56 → v57 при загрузке, старые ключи не удаляются. `state.goal` остаётся главной целью, новые цели — в `state.goals[]`, задачи — в `state.tasks[]`, у заметок появилась `category` (старые = «Личные»).
- Перед миграцией сохраняется нетронутая копия V56: `LIFE_CONTROL_PRE_V57_BACKUP`. Перед первой записью в облако сохраняется копия облачной строки: `LIFE_CONTROL_PRE_V57_CLOUD_BACKUP`. Обе копии дублируются в IndexedDB.
- **Перевод** — новый тип операции: кошелёк → цель, цель → кошелёк, кошелёк → долг. Накопления каждой цели переезжают вместе с ней, поэтому смена главной цели и удаление цели не искажают кассу.
- `schema_version` 57 в коде, SQL и тестах. Живую таблицу менять не нужно.
